# ibm

IBM SkillsBuild AI Experiential Learning Lab - Submission Code Repo

Here is the code for  submission in IPython notebook format (i.e., `.ipynb`).

This is a healthcare chatbot that screens users for social determinants of health before providing the solutions they are seeking. This bot was inspired by the requirements for non-profit healthcare facilties including hospitals, to understand and serve the demographic they provide services to with the appropriate method of care while understanding their current needs and how it affects their health. This would help healthcare facilities to become Accountable Care Organizations (ACOs), which helps these facilities to get the most out of the federal reimbursements via Medicare and Medicaid, as well as deliver quality care and support to patients.
